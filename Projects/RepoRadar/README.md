\# RepoRadar



> Scan. Analyze. Improve.



RepoRadar turns any public GitHub repository URL into a health score,

visual analytics, README audit, tech-stack detection, and a downloadable

PDF report — no sign-up, no database, all analysis done live.



\- \*\*Live demo:\*\* https://repo-radar-23.vercel.app/

\- \*\*Full source code:\*\* https://github.com/HarshilxAI/RepoRadar

\- \*\*Tech stack:\*\* Java 21 + Spring Boot (backend), React + Vite + Tailwind CSS + Chart.js (frontend)
